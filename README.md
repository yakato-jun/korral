# korral

Claude Code のセッションを多数並べて使うときに、どのセッションがどのターミナルのペインで何をしているか、
いま誰の番か、閉じてよいかを、一画面で見るための自分用の Web ダッシュボード。

名前は corral（散らばった家畜を集める囲い）のもじり。

## 状態

作り始め。まだ動くものはない。

## 方針

- この PC の中だけで動かす（`localhost` でだけ開く）。
- 読むのは、この PC にある Claude Code のセッションの記録と、ターミナル（Terminator）の情報。
  それらの中身（会話の記録、セッション名、パス）はリポジトリに入れない。試験のデータは作り物にする。
- 表示の中心は、記録からコードで決まるもの（どのペインか、誰の番か、最後に動いた時刻）にする。
  AI の API は、1 行の要約など、言葉にする所にだけ使い、判断には使わない。
